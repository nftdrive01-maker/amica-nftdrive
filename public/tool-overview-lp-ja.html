Ark-i / injection-tool

情報更新に強いAI接客基盤を、
最小運用で。

Ark-i は Amica に動的知識注入を提供する管理ツールです。ドメイン別プロンプト、MCP外部ツール連携、 同時接続制御（待機画面付き）を一体化し、現場運用で起きる「情報鮮度」と「混雑」を同時に解決します。

管理画面を開く Amicaを開く

ドメイン別運用

相談・施設案内・告知など用途ごとにナレッジとMCPを切替。現場チームがノーコードで更新できます。

最新情報の取り込み

MCP経由で外部データを都度取得し、回答に反映。古い静的プロンプト依存から脱却します。

公開時の混雑制御

公開管理で同時接続上限を全体管理。満席時は待機画面へ誘導し、LLM/TTS過負荷を予防します。

解決できる課題

課題1: 情報更新が遅い ドキュメント修正や再デプロイ待ちが発生し、現場の最新情報が会話に反映されない。
課題2: 役割ごとに回答を分けたい 同じAIに複数業務を背負わせると精度が落ちる。ドメイン単位の文脈分離が必要。
課題3: VPN公開時の同時利用が不安 同時接続急増でLLM/TTS遅延。入口制御と待機導線がないと体験が崩れる。
課題4: 外部ツール連携が複雑 MCPサーバーの登録・切替・運用の標準化が難しい。

システム連携フロー

主な機能

管理者向け

  • ドメイン管理（Prompt / Context / ナレッジ）
  • MCP管理（import / update / route）
  • 公開管理（同時接続上限と現在接続数）
  • アセット管理（VRM / 背景）

利用者向け

  • 混雑時は待機画面を表示（空きで自動接続）
  • 回答中URLはクリック導線で表示
  • TTSはURL読み上げを自動除去
  • ドメインに応じた音声モデル切替

導入ステップ（最短）

Step 1SBV2 と injection-tool を起動し、管理画面ログイン情報を設定。
Step 2Amica の Injection URL を指定し、ドメインとナレッジを作成。
Step 3MCPサーバーをインポートし、対象ドメインへ紐付け。
Step 4公開管理で同時接続上限を設定し、VPN公開前に負荷試験。
